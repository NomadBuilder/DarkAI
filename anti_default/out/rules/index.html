Colonial & Eurocentric

Language that centers Western defaults or frames non-Western peoples as lesser or newly found by outsiders.

  • Discovery framing

    Worth fixing/\bdiscovered\b/i

    “Discovered” often erases Indigenous presence and agency. Prefer language that names arrival, contact, or colonization.

    Try: encountered · arrived in · first documented by [who] among [people already living there]

    Sources · Conscious Style Guide — discovery framing · Native American Journalists Association

    discover-land

  • “New World”

    Worth fixing/\bnew world\b/i

    Treats the Americas as empty or newly real only upon European arrival.

    Try: the Americas · Turtle Island (when appropriate) · Abya Yala

    Sources · Conscious Style Guide — colonial language

    new-world

  • “Old World”

    Consider/\bold world\b/i

    Reinforces a Eurocentric map of history as the default timeline.

    Try: Europe, Africa, and Asia · Afro-Eurasia · name the regions

    Sources · Conscious Style Guide — Indigenous & colonial language · Native American Journalists Association

    old-world

  • “Third World”

    Worth fixing/\bthird[- ]world\b/i

    Cold War hierarchy that ranks countries as behind a Western “first.”

    Try: Global South · low- and middle-income countries · name the specific regions or countries

    Sources · World Bank — income classifications (vs “Third World”)

    third-world

  • “First World”

    Consider/\bfirst[- ]world\b/i

    Implies Western nations are the developmental default.

    Try: high-income countries · Global North · name the countries

    Sources · World Bank — income classifications

    first-world

  • “Developing” countries

    Consider/\bdeveloping (?:country|countries|nation|nations|world)\b/i

    Implies a single Western path of “development.” Use more precise economic or geographic terms when possible.

    Try: low- and middle-income countries · countries with emerging economies · name the region or country

    Sources · World Bank — country classifications by income

    developing-country

Racialized & othering

Coded or overt language that racializes, exoticizes, or others people.

  • Whitelist / blacklist

    Consider/\b(?:whitelist|blacklist)(?:ed|ing|s)?\b/i

    Pairs “white/black” with good/bad. Prefer functional terms.

    Try: allowlist / denylist · permit list / block list

    Sources · Conscious Style Guide — whitelist/blacklist

    whitelist-blacklist

  • Master/slave metaphor

    Worth fixing/\bmaster[/\-]slave\b/i

    Evokes slavery; many style guides recommend primary/replica or similar.

    Try: primary/replica · main/secondary · leader/follower

    Sources · GitHub — Renaming default branch from master · Conscious Style Guide — tech metaphors

    master-slave

  • “Nude” as default skin tone

    Consider/\bnude\b(?=\s+(?:color|tone|shade|lipstick|heel|nail))/i

    Often codes light skin as the neutral default.

    Sources · APA Style — Racial and ethnic identity · Conscious Style Guide

    skin-tone-nude
